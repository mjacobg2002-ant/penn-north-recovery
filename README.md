# Penn North Recovery — Website Redesign Concept

A modern, mobile-first redesign concept for **Penn North Recovery** (Maryland Community Health Initiatives), a nonprofit addiction recovery and community wellness center in West Baltimore.

This is a **presentation shell / draft** built to show the owner a cleaner, easier-to-navigate, more modern direction versus the current site at penn-north.com.

## Highlights
- Single-file `index.html` — no build step, deploys anywhere
- Trauma-informed, hopeful visual language (teal + warm gold)
- Clear paths: Services, Levels of Care, Wellness, Get Started, Contact
- Crisis/help banner (988) always visible
- Drop-in / walk-in emphasis, callback request form (demo)
- Fully responsive, accessible, fast

## Content status
All content is drawn from public listings about Penn North and should be **verified with the owner** before launch:
- Confirm services, levels of care, hours, phone, email, address
- Statistics ("25+ years", etc.) are illustrative placeholders — confirm real figures
- Add real photos, staff bios, and testimonials
- Wire the contact form to a real intake/email backend

## Local preview
Open `index.html` in any browser, or run:
```
python3 -m http.server 8000
```
then visit http://localhost:8000
